# Writing a task

1. Copy `tasks/_template/` to `tasks/<category>/<task_id>/`.
2. Fill `task.json` and `README.md`.
3. Solve it yourself into `reference/`; the grader must accept it.
4. Run the grader on the untouched `env/`; it must reject it.
5. Run the grader on the same final state several times; the result must not change.
